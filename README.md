HOW THIS SITE IS ORGANIZED
1. <style>   all colors, fonts, and layout (top of the file)
2. <body>    the page itself, one <section> per part, each with a label
3. <script>  small bits of behavior (bottom of the file)

THINGS THAT CHANGE OFTEN: search the file for the word  EDIT:
- Proposal form link
- Officer names
- Events timeline
- Meeting day, time, and room
- Project cards
- Email, Discord, Instagram, and Linktree links

PHOTOS: all photos live in a folder called  images/  next to this file.
The file names used below are listed in the comment above each section.
If a photo is a .png instead of a .jpg, just change the ending in the
<img src="..."> line.

COLORS: change them once here and the whole site updates.
